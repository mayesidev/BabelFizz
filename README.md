# BabelFizz

A project to implement a solution for FizzBuzz in different programming languages.

## FizzBuzz Description

Print out sequential numbers from 1 to n, except when the number is divisible by-

* 3, then print "Fizz" instead.
* 5, then print "Buzz" instead.
* Both 3 and 5, then print "Fizz Buzz" instead.

See [expected-output.txt](.\expected-output.txt) for an example where n=100.

## AI Notice

While I leverage AI in my other work at times, all of the implementations in this repo have been written without the help of AI (many prior to its broad, general availability), and often with little-to-no syntax help from autocomplete or other intellisense-like features. The goal of this project has always been to explore different programming languages and consider the impact their syntactical and development patterns have on approaching the implementation of a common logic problem that includes simple requirements such as mathematical functions, loops, reading input, and generating output.
